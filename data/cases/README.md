## 四件套结构（可复现的关键）

每个案例 JSON 都包含四个部分：

1. `baseline` 基线：体测数据 + 目标 + 起始日期
2. `plan` 方案：当时开出的阶段方案（含 `why` 推理，供「方案回放」复现）
3. `process` 过程：每周打卡时间线（体重/体脂/完成率/Coach 备注/调整记录）
4. `result` 结果：最终数据 + 变化量 + 总结

另外 `narrative` 字段用于网站案例页的故事化展示。
